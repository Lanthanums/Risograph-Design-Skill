# Decoration and hierarchy

Read when debugging placement or changing the placement engine. Numeric rules
live in `place_decor.TEXT_TIERS`, `compose.DENSITY`, and `riso_kit.DESIGN`; query
the design-system CLI rather than copying tables into prompts.

- One protagonist: typography, content image/diagram, or an optional element.
  Large type already occupies that role. Extra elements must be subordinate.
- Decoration budgets tighten with text load. No area/count floor exists. For a
  poster, resolve a graphic concept alongside typography; an empty list should
  be deliberate. Never fill holes or shrink a hero into confetti.
- Measure glyph ink first, including misregistered layers. Inflate the ink for
  protection. Place decor next to a supplied anchor, at an edge, as a coherent
  group, or as a genuinely justified hero in a sufficiently large empty region.
- Every element carries an anchor/emphasis/rhythm/metaphor/component function.
  If its relation cannot be explained, omit it. Never let decoration invent copy.
- A group shares alignment and ink, with visible size contrast. Rotation reserves
  the rotated footprint, not only the unrotated shape frame.
- Deck chrome is chosen once for the deck and consumes the budget. Its bands
  protect labels. Poster has no deck chrome and uses its own safe/bleed policy.
- Keep the primary dialect coherent; secondary accents are rationed by the
  shared engine. Texture and print marks are dialect-neutral.
- Highlights cover actual target glyphs; offsets adapt to type size. Read
  `geometry.md` for fit and font failures, not another numeric rule table here.

Quiet space is a contiguous measured region, not a minimum decoration quota.
Distributed deck diagrams use the existing documented exception. A poster's
full-bleed exception requires an explicit content reason and a real full-bleed
image. It never exempts text safety, overflow, hierarchy, palette, or collisions.

Content pages retain claim, support, and an anchor. Density counts are proxies;
an agent must check meaning against source material. Do not dilute content or add
divider pages to create decorative room or to pass rhythm.
