# Poster dialects

Every dialect uses measured native text, title ink registration, quiet generated
paper, trim registration and one accent. Explicit dialect overrides content defaults.

| Dialect | Default intent | Material system |
|---|---|---|
| swiss | Comparable evidence/chart | Ordered columns, graphic band, title offset, accent |
| collage | Editorial modules/quotation | Every supporting module gets consistent paper and tape |
| doodle | Source sequence | Every module gets hand-line treatment; process gets a numbered chain |

skeleton:auto is content-based, not seed parity. bands, asymmetric-notes and
central-orbit retain a declared column reading path. central-orbit reserves the
hero above columns; it does not zigzag source modules. Capacity fallback to bands
retains dialect materials.

looseness 0..1 changes edge/mark amplitude, not random inclusion. Swiss clamps to 0 with a warning.
surface_seed changes surfaces without changing measured structure. Body stays
horizontal. halftone:auto uses the reserved recipe pattern when available; omissions
are reported. No loose field behind body. micro_style marks a supplied CTA;
it does not invent badge words.

layout.graphic:none declares intentional typography. QA can detect missing
hero/material signals but cannot grade subject relevance or design maturity.
Always inspect the default result.
