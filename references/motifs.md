# Composition relationships

Motifs are ideas for organizing content, not fixed artwork or element quotas.
The stock deck builder uses its archetype geometry; `pages[].motif` is only a
decoration-planner hint and does not implement an alternate layout. Poster uses
the layout controls in [poster.md](poster.md). Custom arrangements must still
pass shared Canvas, font, collision, hierarchy and quiet-space checks.

| Relationship | Useful content | Visual treatment |
|---|---|---|
| tabletop / spread | Reflection, contrast | Aligned collage group or opposing regions |
| annotation / notebook | Teaching, supplied relationships | Connected diagram with close marks and handwritten accents |
| band_split / magazine_grid | Data, reports, events | Measured columns/bands with unequal content-driven heights |
| diagonal_cut / badge_centre | Turning point, thesis | One directional shape or contained visual anchor |
| list_form / serpentine | Supplied steps or chronology | Readable sequence; connectors only for stated relationships |
| comic_panels / stacked_windows | Narrative, product explanation | Related frames with deliberate reading order |
| pure_type | Explicit typography-led treatment | Monumental editable type with optional restrained marks |
| sticker_sheet | A real set of related concepts | Coherent group with clear scale contrast; no count quota |

Choose a relationship from the source, then resolve scale and spacing with actual
content. Preserve one leading subject. Shapes support meaning or rhythm, never
invent metadata. No motif overrides the engine's decoration ceilings or justifies
copying a finished reference layout. Palette, dialect and print treatment can
vary without turning every page into the same skeleton.
